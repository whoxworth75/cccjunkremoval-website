# Chaos Cleanup Crew Junk Removal Website

Static one-page website for Chaos Cleanup Crew Junk Removal.

## Publish with GitHub Pages

1. In GitHub, open **Settings** for this repository.
2. Open **Pages** in the left menu.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then save.
5. GitHub will provide a public `github.io` address.

## Connect cccjunkremoval.com

At Namecheap, add these records in Advanced DNS:

- `A` record, host `@`, value `185.199.108.153`
- `A` record, host `@`, value `185.199.109.153`
- `A` record, host `@`, value `185.199.110.153`
- `A` record, host `@`, value `185.199.111.153`
- `CNAME` record, host `www`, value `whoxworth75.github.io`

Then in GitHub Pages settings, enter `cccjunkremoval.com` under Custom domain and enable **Enforce HTTPS** after the certificate is ready.
